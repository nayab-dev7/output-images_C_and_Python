# Programming Practice (C++ & Python)

A collection of my programming practice, assignments and output screenshots, written while studying Artificial Intelligence at Aror University, Sukkur. Most of the work here is C++ basics, with some Python mixed in.

This repository is updated regularly as I learn new topics.

## Topics Covered

- Printing output (`cout`) and `using namespace std` vs `std::cout`
- Variables, data types (`int`, `float`, `double`)
- Arithmetic operators (sum, minus, multiply, divide)
- Bitwise operators (AND, OR, XOR)
- `if` / `else` statements
- `switch` statements
- `for` loops and `while` loops
- Same program in C++ and Python (sum)
